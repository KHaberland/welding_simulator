# Техническое задание

## MAG Welding Trainer — интерактивный учебный симулятор сварки MAG

**Версия:** MVP 1.0
**Платформа:** Web
**Технологии:** HTML5, CSS3, JavaScript ES6+, Canvas 2D, Web Audio API / audio samples
**Backend:** не требуется для MVP
**Основная цель:** визуально и интерактивно показать начинающему сварщику причинно-следственную связь между скоростью подачи проволоки, сварочным током, напряжением, длиной дуги, короткими замыканиями, переносом капель, сварочной ванной и проплавлением.

---

# 1. Цель проекта

Создать браузерный интерактивный тренажёр сварки MAG, который позволяет ученику самостоятельно изменять параметры сварочного процесса и наблюдать результат.

Тренажёр должен работать не как заранее записанная анимация, а как **упрощённая динамическая модель сварочного процесса**.

Пользователь изменяет параметры, модель рассчитывает состояние процесса, а Canvas в реальном времени отображает:

* подачу проволоки;
* сварочный ток;
* напряжение;
* длину дуги;
* короткие замыкания;
* образование и перенос капель;
* сварочную ванну;
* валик;
* проплавление;
* стабильность процесса;
* характер сварочного звука.

Главный учебный принцип:

**WFS → ток → длина дуги → частота коротких замыканий → перенос капель → сварочная ванна → проплавление**

---

# 2. Назначение тренажёра

Тренажёр предназначен прежде всего для начинающих сварщиков.

После объяснения преподавателя ученик должен иметь возможность открыть тренажёр на компьютере или телефоне и самостоятельно экспериментировать с параметрами.

Тренажёр должен помочь понять:

1. что скорость подачи проволоки непосредственно связана со сварочным током;
2. что ток не устанавливается пользователем непосредственно;
3. что напряжение влияет прежде всего на длину дуги;
4. что правильное сочетание WFS и напряжения обеспечивает устойчивый процесс;
5. что слишком высокая подача проволоки при недостаточном напряжении приводит к чрезмерно частым коротким замыканиям;
6. что слишком высокое напряжение при недостаточной подаче проволоки приводит к слишком длинной дуге и крупным каплям;
7. как меняется частота переноса капель;
8. как изменяются сварочная ванна и проплавление;
9. как изменяется звук процесса.

---

# 3. Общая концепция MAG-процесса

В MVP моделируется преимущественно **MAG с короткозамкнутым переносом металла (short-circuit transfer)**.

Процесс должен быть представлен как последовательность физических событий.

После нажатия START:

1. начинает подаваться сварочная проволока;
2. дуги первоначально нет;
3. проволока выходит из сопла;
4. проволока касается металла;
5. возникает электрическое короткое замыкание;
6. участок проволоки быстро нагревается;
7. небольшой участок проволоки расплавляется;
8. расплавленный металл отделяется от основной проволоки;
9. возникает электрическая дуга;
10. дуга нагревает конец проволоки;
11. формируется жидкая капля;
12. одновременно поддерживается расплавленная сварочная ванна;
13. капля движется к сварочной ванне;
14. при контакте с ванной капля отделяется от проволоки;
15. длина дуги кратковременно увеличивается;
16. дуга восстанавливается;
17. на конце проволоки начинает формироваться следующая капля;
18. цикл повторяется.

Основной цикл:

**DROPLET FORMATION → SHORT CIRCUIT TRANSFER → ARC RECOVERY → DROPLET FORMATION**

---

# 4. Геометрия сцены

Использовать **боковой вид сварочного процесса**.

Не использовать вид сверху.

В нижней части Canvas располагается металлическая пластина, показанная в разрезе.

В верхней части отображается только рабочая часть горелки:

* сопло;
* конец проволоки;
* дуга.

Проволока расположена вертикально.

Угол проволоки к поверхности:

**90°**

В MVP отсутствуют:

* наклон горелки;
* движение вправо/влево;
* скорость перемещения;
* поперечные колебания.

Принципиальная схема:

```text
              NOZZLE
             ┌─────┐
             │     │
             └──┬──┘
                │
                │ wire
                │
               🔥
             ╱~~~~╲
           ╱~~~~~~~~╲
════════════════════════  surface
████████████████████████  metal
        ↓↓↓↓↓             penetration
```

1. сопло;

Нельзя использовать одну статическую картинку сварки как основное представление процесса.

### 6.3. Напряжение

# 7. Что пользователь НЕ регулирует

В MVP пользователь не устанавливает непосредственно:

* ток;
* проплавление;
* длину дуги;
* частоту коротких замыканий;
* размер капли;
* размер сварочной ванны.

Эти параметры являются **результатом выбранных пользователем настроек**.

Это принципиально важно с точки зрения обучения.

---

# 8. Логика сварочного тока

Ток не должен рассчитываться просто как `I = U / R`.

Для тренажёра используется эмпирическая модель зависимости тока от скорости подачи проволоки.

Основная зависимость:

**I ≈ WFS / K**

или:

**WFS ≈ I × K**

где:

* `I` — сварочный ток, A;
* `WFS` — скорость подачи проволоки, m/min;
* `K` — эмпирический коэффициент.

---

# 9. Коэффициенты K для разных диаметров проволоки

### Ø0.8 mm

**K = 0.05**

### Ø1.0 mm

**K = 0.038**

### Ø1.2 mm

**K = 0.025**

Примеры для 160 A:

| Диаметр |        WFS |
| ------- | ---------: |
| 0.8 mm  |  8.0 m/min |
| 1.0 mm  | 6.08 m/min |
| 1.2 mm  |  4.0 m/min |

---

# 10. Динамический ток

Базовый ток:

`I_base = WFS / K`

Но фактический ток должен рассчитываться динамически.

На фактический ток могут влиять:

* длина stick-out;
* состояние дуги;
* короткое замыкание;
* процесс образования капли;
* восстановление дуги;
* нестабильность процесса.

Поэтому:

`I_actual = I_base + dynamic_correction`

Коррекция должна быть ограниченной, чтобы процесс не превращался в случайную анимацию.

Все коэффициенты должны храниться в конфигурации и быть доступны для последующей калибровки.

---

# 11. Диапазоны тока для проволоки

Использовать следующие ориентировочные диапазоны:

| Диаметр | Диапазон |
| ------- | -------: |
| Ø0.8 mm | 40–145 A |
| Ø1.0 mm | 60–230 A |
| Ø1.2 mm | 75–250 A |

Эти значения могут использоваться для:

* визуального индикатора;
* определения явно нештатного режима;
* подсказок пользователю.

---

# 12. Рекомендуемый ток по толщине

В следующем этапе развития тренажёра можно использовать зависимость:

**I ≈ S × 40**

где:

* `S` — толщина металла в mm;
* `I` — рекомендуемый ток.

Например:

**4 mm → примерно 160 A**

Это является ориентиром для выбора рабочего режима, а не непосредственным расчётом фактического тока.

В MVP толщина металла **фиксирована** и пользователем не выбирается.

---

# 13. Рекомендуемое напряжение

Использовать ориентировочную зависимость:

**U ≈ 0.04 × I + 14**

Например:

для 160 A:

**U ≈ 20.4 V**

Это также является ориентиром для формирования устойчивого режима.

---

# 14. Связь WFS и напряжения

Пользователь должен наглядно увидеть, что:

* увеличение WFS повышает ток;
* увеличение тока изменяет характер переноса;
* слишком высокая WFS при прежнем напряжении сокращает длину дуги;
* увеличение напряжения увеличивает длину дуги;
* слишком высокое напряжение при низкой WFS создаёт длинную дугу и крупные капли.

Цель пользователя — найти сочетание:

**WFS + Voltage**

при котором процесс становится устойчивым.

---

# 15. Начальное состояние

При загрузке страницы:

* сварка выключена;
* проволока не движется;
* дуги нет;
* сварочной ванны нет;
* ток показывает `--- A`;
* фактическое напряжение показывает `--- V`.

Пользователь выбирает:

* диаметр проволоки;
* WFS;
* напряжение;
* движение горелки.

---

# 16. Нажатие START

После START:

1. начинается подача проволоки;
2. проволока движется вниз;
3. дуги ещё нет;
4. конец проволоки приближается к металлу;
5. происходит касание металла;
6. возникает короткое замыкание;
7. конец проволоки начинает быстро нагреваться.

Это состояние должно быть визуально заметным.

---

# 17. Короткое замыкание и зажигание дуги

При контакте проволоки с металлом:

* дуга исчезает;
* контактная зона становится яркой;
* конец проволоки визуально нагревается;
* небольшой участок проволоки начинает плавиться.

После отделения расплавленного участка:

* возникает дуга;
* дуга начинает плавить конец проволоки;
* формируется капля.

---

# 18. Формирование капли

В устойчивом процессе:

* капли относительно небольшие;
* формируются регулярно;
* имеют относительно стабильный размер;
* движутся к сварочной ванне;
* при контакте с ванной отделяются.

После отделения капли:

* расстояние между концом проволоки и ванной кратковременно увеличивается;
* дуга восстанавливается;
* начинается образование следующей капли.

---

# 19. Short-circuit transfer

Основной цикл:

```text
WIRE
  ↓
DROPLET FORMATION
  ↓
DROPLET CONTACT WITH POOL
  ↓
SHORT CIRCUIT
  ↓
DROPLET TRANSFER
  ↓
ARC RECOVERY
  ↓
NEW DROPLET
```

Частота этого цикла зависит от выбранного режима.

---

# 20. Влияние увеличения WFS

При увеличении WFS:

* увеличивается сварочный ток;
* проволока быстрее подаётся в зону дуги;
* при соответствующем увеличении напряжения может увеличиваться частота образования и переноса капель;
* короткие замыкания происходят чаще;
* звук становится более частым и относительно ровным;
* сварочная ванна увеличивается;
* проплавление увеличивается.

Однако увеличение WFS без соответствующей корректировки напряжения приводит к нестабильности.

---

# 21. Слишком высокая WFS / слишком низкое напряжение

Если WFS слишком высокая для выбранного напряжения:

1. проволока подаётся слишком быстро;
2. ей не хватает времени для нормального нагрева и плавления;
3. дуга становится очень короткой;
4. короткие замыкания происходят слишком часто;
5. дуга не всегда успевает восстановиться;
6. частота коротких замыканий продолжает возрастать;
7. процесс становится нестабильным;
8. в крайнем случае дуга перестаёт восстанавливаться;
9. проволока начинает просто упираться в металл/сварочную ванну;
10. проволока размягчается и ложится сверху;
11. сварочный процесс прекращается.

Визуально:

* короткая дуга;
* частые короткие замыкания;
* резкие изменения яркости;
* возможные прерывания дуги;
* при крайнем режиме — прекращение нормального плавления.

---

# 22. Слишком высокое напряжение / слишком низкая WFS

Если напряжение слишком высокое относительно WFS:

1. после первоначального контакта расплавляется больший участок проволоки;
2. образуется крупная капля;
3. дуга становится длинной;
4. дуга визуально может подниматься ближе к соплу;
5. капля растёт;
6. капля отделяется позднее;
7. место её попадания становится менее предсказуемым;
8. перенос происходит отдельными крупными каплями;
9. процесс становится нестабильным.

Визуально:

* длинная дуга;
* крупная капля;
* редкие переносы;
* большие отдельные импульсы;
* менее стабильная сварочная ванна.

---

# 23. Стабильный процесс

Стабильный процесс должен находиться в некотором диапазоне сочетаний WFS и напряжения.

В стабильном режиме:

* дуга регулярно зажигается и восстанавливается;
* короткие замыкания происходят регулярно;
* размер капель относительно стабилен;
* сварочная ванна поддерживается;
* валик формируется равномерно;
* проплавление имеет устойчивый характер;
* звук становится относительно равномерным.

---

# 24. Состояния сварочного автомата

Использовать следующие состояния:

```text
IDLE
WIRE FEED
SHORT CIRCUIT / IGNITION
ARC IGNITION
DROPLET FORMATION
SHORT CIRCUIT TRANSFER
ARC RECOVERY
```

Основной цикл:

```text
DROPLET FORMATION
        ↓
SHORT CIRCUIT TRANSFER
        ↓
ARC RECOVERY
        ↓
DROPLET FORMATION
```

Дополнительно необходимо предусмотреть:

```text
UNSTABLE — LOW VOLTAGE / HIGH WFS
UNSTABLE — HIGH VOLTAGE / LOW WFS
ARC FAILURE
```

---

# 25. Stick-out

Базовый stick-out:

**15 mm**

При выключенном движении горелки:

**stickOut = 15 mm**

При включённом движении:

**12–18 mm**

Изменение должно быть:

* плавным;
* псевдослучайным;
* без резких скачков;
* непрерывным во времени.

Пользователь не должен напрямую задавать stick-out.

---

# 26. TORCH MOVEMENT

При включении:

**TORCH MOVEMENT ON**

модель создаёт небольшие плавные изменения stick-out.

Движение начинается только после начала сварки/зажигания дуги.

При выключении:

**TORCH MOVEMENT OFF**

stick-out остаётся постоянным на уровне 15 mm.

В MVP движение не должно включать:

* боковое перемещение;
* наклон;
* колебания;
* изменение скорости сварки.

---

# 27. Влияние stick-out

Изменение stick-out должно влиять на модель.

Возможные эффекты:

* небольшое изменение фактического тока;
* изменение условий нагрева проволоки;
* небольшое изменение фактического напряжения;
* изменение длины дуги;
* небольшое изменение размера капли;
* изменение стабильности.

Эффект должен быть заметным, но не настолько сильным, чтобы небольшой диапазон 12–18 mm полностью разрушал процесс.

---

# 28. Фактическое напряжение

`voltageSet` является пользовательским заданием.

`voltageActual` рассчитывается отдельно.

Фактическое напряжение должно:

* находиться около установленного значения;
* иметь небольшие динамические изменения;
* реагировать на состояние дуги;
* изменяться при коротком замыкании;
* зависеть от stick-out и стабильности.

Перед началом сварки:

**--- V**

После зажигания:

например:

**20.3 V**

при заданных:

**20.4 V**

---

# 29. Длина дуги

Длина дуги не является непосредственным пользовательским параметром.

Она рассчитывается моделью на основе:

* установленного напряжения;
* текущего процесса;
* WFS;
* stick-out;
* состояния короткого замыкания.

При коротком замыкании:

**arcLength ≈ 0**

При восстановлении:

дуга снова появляется и увеличивает gap.

При слишком высоком напряжении:

дуга становится визуально длиннее.

При слишком низком напряжении относительно WFS:

дуга становится короткой и может часто исчезать.

---

# 30. Модель сварочной ванны

Сварочная ванна должна быть динамической.

Параметры:

* width;
* length;
* depth;
* brightness/temperature;
* surface dynamics;
* response to droplet impact.

Ванна должна изменяться в зависимости от:

* тока;
* напряжения;
* стабильности;
* количества переносимого металла;
* состояния процесса.

---

# 31. Валик

На поверхности металла постепенно формируется сварочный валик.

Валик должен:

* увеличиваться по мере сварочного процесса;
* реагировать на количество перенесённого металла;
* иметь динамическую поверхность;
* соответствовать размеру сварочной ванны.

В MVP не требуется моделировать движение сварочного шва по длине.

---

# 32. Проплавление

Проплавление должно отображаться **визуально в разрезе металла**.

Это не должно быть только числовое значение.

Упрощённая модель:

**penetration = f(current, voltage, materialThickness, stability)**

При низком токе и напряжении:

* небольшая ванна;
* неглубокое проплавление.

При увеличении тока и соответствующем увеличении напряжения:

* увеличивается сварочная ванна;
* увеличивается глубина проплавления.

Толщина пластины в MVP фиксирована.

---

# 33. Связь тока и проплавления

Для учебной модели:

* низкий ток → небольшое проплавление;
* средний стабильный ток → нормальное проплавление;
* более высокий ток при соответствующем напряжении → большее проплавление.

Модель должна быть ограничена физически разумным диапазоном.

Нельзя допускать, чтобы небольшое изменение WFS давало визуально экстремальное изменение проплавления.

---

# 34. Индикация стабильности

Можно предусмотреть индикатор:

**STABILITY**

Например:

* STABLE;
* WARNING;
* UNSTABLE.

В числовой модели:

```javascript
stability = 0.0 ... 1.0
```

где:

* `1.0` — устойчивый процесс;
* около `0.5` — нестабильность;
* около `0` — потеря устойчивости.

---

# 35. Отображение параметров

До начала сварки:

```text
WIRE Ø       1.0 mm
WIRE FEED    6.1 m/min
VOLTAGE      20.4 V
CURRENT      --- A
```

После зажигания:

```text
WIRE Ø       1.0 mm
WIRE FEED    6.1 m/min
VOLTAGE      20.4 V
ACTUAL V     20.3 V
CURRENT      160 A
```

Дополнительно:

```text

```

В дальнейшем возможно отображение:

```text

```

но интерфейс MVP не должен быть перегружен.

---

# 36. Визуализация дуги

Дуга должна быть динамической.

Необходимо отображать:

* яркое ядро;
* внешнее свечение;
* изменяющийся контур;
* изменение длины;
* изменение ширины;
* изменение интенсивности.

Параметры дуги зависят от:

* тока;
* напряжения;
* stick-out;
* состояния процесса;
* стабильности.

Во время короткого замыкания:

**дуга должна исчезать.**

После переноса:

**дуга должна снова зажигаться.**

При полном ARC FAILURE:

**дуга остаётся погашенной.**

---

# 37. Визуализация проволоки

Проволока должна двигаться непрерывно при включённой подаче.

Скорость визуального движения пропорциональна WFS.

При коротком замыкании конец проволоки должен визуально взаимодействовать с ванной.

При ARC FAILURE:

* проволока может продолжать подаваться;
* но нормального дугового процесса нет;
* она упирается в металл/ванну;
* процесс считается остановленным.

---

# 38. Визуализация капель

Капля является отдельным динамическим объектом.

Параметры:

* x;
* y;
* radius;
* velocity;
* temperature;
* lifetime;
* state.

В стабильном режиме:

* меньший размер;
* высокая частота;
* относительно регулярный перенос.

При высоком напряжении и низкой WFS:

* большая капля;
* низкая частота;
* менее предсказуемый момент отделения;
* менее предсказуемая точка попадания.

---

# 39. Поведение при попадании капли

Когда капля касается сварочной ванны:

1. происходит короткое замыкание;
2. капля отделяется от проволоки;
3. капля исчезает как отдельный объект;
4. её масса добавляется к сварочной ванне;
5. поверхность ванны получает небольшой импульс;
6. дуга восстанавливается;
7. начинает формироваться следующая капля.

---

# 40. Аудио

Звук должен отражать состояние процесса.

В стабильном режиме:

* частые короткие импульсы;
* относительно равномерный звук;
* менее выраженное «трескание» при увеличении частоты переноса.

При высокой WFS и низком напряжении:

* частые резкие короткие замыкания;
* более выраженное потрескивание;
* возможные прерывания.

При слишком высоком напряжении и низкой WFS:

* редкие крупные импульсы;
* нерегулярный характер звука.

При прекращении дуги:

**звук сварки прекращается.**

---

# 41. Реализация аудио MVP

На первом этапе допускается использование подготовленных audio samples.

Позднее возможно перейти на Web Audio API для динамической генерации звука.

Параметры звука должны быть связаны с:

* частотой коротких замыканий;
* стабильностью;
* током;
* состоянием дуги.

---

# 42. Математическая модель процесса

Все физические зависимости являются **упрощёнными эмпирическими моделями**.

Цель:

не создать физически точный CFD/электродуговой симулятор, а получить визуально и логически убедительную модель для обучения.

Основные зависимости:

```text
WFS → current
current + voltage → arc behavior
arc behavior → short-circuit frequency
short-circuit frequency → droplet transfer
droplet transfer → pool
current + voltage → penetration
process state → audio
```

---

# 43. Конфигурируемые параметры

Все коэффициенты модели должны храниться отдельно.

Например:

```javascript
const WELDING_CONFIG = {
    stickOutBase: 15,
    stickOutMin: 12,
    stickOutMax: 18,

    currentCorrectionLimit: ...,

    arcLengthFactor: ...,

    dropletFrequency: ...,

    shortCircuitThreshold: ...,

    penetrationFactor: ...,

    poolWidthFactor: ...,

    poolDepthFactor: ...
};
```

Это позволит впоследствии калибровать модель по реальным сварочным экспериментам без переписывания всей программы.

Пример структуры:

Дополнительно модель может хранить:

```javascript

beadVolume: 0
```

Тренажёр не должен постоянно подсказывать правильный ответ.

Можно предусмотреть ненавязчивую индикацию:

```text

WARNING
UNSTABLE
```

Но не превращать MVP в тест с готовыми ответами.

# 54. Что считается успешным режимом

Процесс считается устойчивым, если одновременно выполняются приблизительные условия:

* WFS соответствует выбранному диаметру;
* ток находится в разумном диапазоне;
* напряжение соответствует току;
* дуга регулярно восстанавливается;
* капли формируются и переносятся регулярно;
* ванна поддерживается;
* нет постоянного короткого замыкания;
* нет чрезмерно длинной дуги;
* стабильность выше установленного порога.

# 63. Итоговая концепция

Это не видеоролик о сварке и не интерактивная картинка.

Это **упрощённая динамическая модель короткозамкнутого MAG-процесса**, в которой пользователь управляет двумя основными параметрами:

**Wire Feed Speed**

и

**Voltage**

а остальные параметры являются следствием их взаимодействия.

Главная учебная задача:

показать начинающему сварщику, почему невозможно рассматривать скорость подачи проволоки, ток и напряжение как три независимых регулятора.

Тренажёр должен дать ощущение:

> **«Я изменил параметр → процесс изменился → я вижу и слышу почему».**

Именно эта причинно-следственная связь является главным результатом MVP.
